# Publishing method (posting kit, LinkedIn, gates)

1. **Research before writing** (never from memory): `python3 -I scripts/seo_research.py "<topic>" "<related>" --out <proj>/seo_research.json`, plus web searches for (a) what is trending, (b) what top videos/titles look like, (c) a primary source for every fact the copy states. Write `research_notes.md`: what people type, what you verified (with sources), what you could NOT verify (and therefore do not claim), the keyword decision (1 primary + 3 secondary).
2. **Write the kit** from `assets/posting-kit-template.md`; run `python3 scripts/kit_lint.py <proj>/posting_kit.md` until PASS (title <= 60, tags 470-500 chars, <= 5 Instagram hashtags, no duplicates, metadata language). `publish_check.py` also runs an extra linter if `kit_lint` is set in `config.local.json`.
3. **LinkedIn** (`linkedin_post.md`): first person, calm and specific, no hype words or invented stats; hook in the first ~150 characters (not a question, no emoji opener); 150-250 words in short paragraphs; one concrete example, the plain explanation, up to 3 takeaway bullets; one open question to close (not engagement bait); <= 2 emoji, 3 hashtags at the end; **no links in the body** (put sources in the first comment). Image: `python3 -I scripts/make_linkedin_image.py <proj> --kicker ... --headline "Don't *create*. Reuse." --points "a|b|c"` (1080x1350, in the video's look).
4. **Covers**: `meta.cover` then `scripts/make_cover.py` (A = hero frame, B = a reveal frame; promise <= 8 words; the 3:4 feed crop is checked in `covers/grid_check.png`).
5. **Gates**: `qa_explainer.py` (video + audio), `safe_zone_check.py` (platform UI zones), `publish_check.py` (checklist: headline, covers, srt, kit lint, research, facts, safe-zone, music licence, voice report).
6. **Upload** only after the creator approves both the video and the covers: `upload_drive.sh <proj> --approved-video --approved-cover` (dry run first). The script refuses without both flags.
